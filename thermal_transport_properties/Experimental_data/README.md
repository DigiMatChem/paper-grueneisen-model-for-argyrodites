# Experimental data 

This repository includes experimental raw data supporting the manuscript titled *“Thermal Transport in Ag<sub>8</sub>TS<sub>6</sub> (T= Si, Ge, Sn) Argyrodites: An Integrated Experimental, Quantum-Chemical, and Computational Modelling Study”*  


### **DC** 
- Includes the Direct current polarisation measurements to determine the electronic conductivity 
---

### **Impedance_spectroscopy**  

- Includes electrochemical impedance spectroscopy dataset performed over the temperature range 233-303 K

---
### **LFA — Laser Flash Analysis**  
- Thermal transport properties including diffusivity, heat capacity and lattice thermal conductivity. 
---

### **PPMS** 

- Physical Property Measurement System (PPMS) for the lattice thermal conductivity at low temperature of Ag<sub>8</sub>GeS<sub>6</sub> argyrodite
---
### **RbAg<sub>4</sub>I<sub>5</sub>** 

Results of the electrode reference material RbAg<sub>4</sub>I<sub>5</sub>:

- Impedance: Direct current polarisation measurements
- XRD: X-ray diffraction patterns including their corresponding Rietveld refinement results at 298K

---
### **SOS**

- Includes the speed of sound and derived properties for all the structures in this work. 

---
## XRD data

- Here, we include X-ray diffraction for all the sulphide-argyrodites:
	- .raw files can be read with TOPAS-Academic V7 
	- .xy file presents the 2-theta values vs intensity

### **T-dependent_XRD**

- X-ray diffraction patterns at all measured temperatures.
---

### **XRD_refinement_298K**

- Rietveld refinements at all 298K  for all three compositions of Ag8TS6 (T = Si, Ge, Sn) using the Topas-Academic V7 software package.
