# Thermal Transport in Ag<sub>8</sub>TS<sub>6</sub> (T= Si, Ge, Sn) Argyrodites: An Integrated Experimental, Quantum-Chemical, and Computational Modelling Study


This repository provides analysis scripts and data processing tools to reproduce the key results from our study on Ag<sub>8</sub>TS<sub>6</sub> (T = Si, Ge, Sn) argyrodites. It integrates quantum-chemical bonding analysis and computational modeling of thermal transport properties.

---
## Repository Structure

- **Bonding Analysis**  
  Scripts to reproduce the two-center and multicenter bonding analysis results can be found in `bonding_analysis/two_center` and `bonding_analysis/multicenter`, respectively. Please refer to the `README` therein for further details.


- **Thermal Transport Properties**  
  Contains results and scripts to reproduce the thermal transport calculations following different modeling approaches described in our work.  
  Please refere to the `README` therein for further details.
