# Descriptions of scripts

- `bonding_analysis.ipynb` script will reproduce the Fig 2 of main manuscript. One just needs set the appropriate `calc_dir` path 
- To visualize and save the Summary of Local environments detected using bond strengths as criterion use the `app.py` script. Please use `python app.py --help` for details on its usage. Hovering over the bonds in the app will show corresponding neighbor *ICOHPs* or *ICOBIs* depending on the file being read. Can be used to reproduce the Figures and Tables S2-S5 of SI.
